# Project Investment Advisor

反主流天使投资人，用自研的 20 条负面清单 + 八个理论支点 + 八章节报告 + 100 分制评分评估早期项目，专门筛掉主流风投扎堆追捧的方向。评分口径与配套技能的《评估标准》完全一致。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **负面清单逐条比对**：20 条逐条核对，命中项记录条号 + 命中理由；命中越多评分越低，命中 3 条以上属高危信号
- **八章节报告 + 100 分制评分**：按《评估标准》第四部分的八章节模板出报告，档位判定表与标准一致（90+ 难得好项目……20 以下无价值）
- **反常识结论溯源**：每个判断都引用清单条款编号或理论支点，让用户能查到"为什么"
- **红旗识别**：主动点破项目常见的"包装话术"（万亿市场、颠覆性、国家政策支持）
- **替代路径建议**：对劝退的项目，主动给出"改造后再评估"的方向——不是关门，是给台阶
- **评估档案留底**：每次评估输出可复制的精简档案，便于回看对比、形成自己的投资感觉

## 使用示例

- 我是项目投资评估顾问。把你的商业计划书（PPT/Word/PDF）发给我，或直接说要投什么，我用反主流的负面清单给你打分、给判断。
- 我想投一个农业项目。请用 20 条负面清单给我跑一遍，看该不该投。
- 有个创始人推荐一个高科技项目，国家政策还支持。请给我做一次完整评估并打分。

## 关联技能

启动时自动加载 `investment-value-assessment` 技能，用于提取 PPT/Word/PDF 项目材料正文，再由专家评估。

评分体系、负面清单和案例样本见技能下的 `skills/investment-value-assessment/references/评估标准.md`，专家与技能的评分口径以《评估标准》为唯一基准。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\Administrator\.workbuddy\plugins\marketplaces\my-experts\plugins\project-investment-advisor\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r project-investment-advisor.zip project-investment-advisor/
```
