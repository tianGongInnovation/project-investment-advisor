# 答复回流记录格式

> 每次拿到工坊作者的答复，除了原样转给用户，还要按本格式沉淀进知识库。
> 存放位置：`references/真人答疑/YYYY-MM.md`（每篇专家包一份，按月追加）

## 单条记录格式

```
## YYYY-MM-DD｜工单号 REL-XXXXXXXX-XXXX

**用户原问**：
（照录）

**专家当时的初步判断**：
（原样保留，用于对账）

**工坊作者答复**：
（原样录入，标注为"作者答复"，不改写、不精简）

**适用边界 / 作者补充的前提条件**：
（如果有）

**可复用到哪些问题**：
（关键词标签，便于后来检索）
```

## 索引更新

每追加一条，同步在 `references/真人答疑/索引.md` 追加一行：

| 日期 | 工单号 | 问题关键词 | 所在文件 |

## 质量要求

1. **原样保留**——作者的原话不能被 AI 改写得"更通顺"，口径变了等于错了；
2. **标注来源**——知识库里引用时写"据工坊作者答复（YYYY-MM-DD）"；
3. **不对冲突内容做调和**——作者答复若与原有资料矛盾，两条并列保留，并注明矛盾点，由作者日后统一，禁止自行二选一。
